The core on each window — separate runs (each starts flat at $100k)

House rule: each window is its own run from $100k, not one continuous account. So the runs are stacked below each other with their own baseline and their own drawdown — nothing is carried across the boundary, which is exactly why a single joined curve would invent a fake drawdown.
